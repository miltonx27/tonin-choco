# Tonín Chocolate — Digital Lettering

First-pass vector reconstruction of the hand-drawn lettering and emblem supplied as references.

## Deliverables

- `01_mayusculas.svg` — uppercase alphabet specimen
- `02_minusculas.svg` — lowercase alphabet specimen
- `03_caracteres_espanol.svg` — Spanish accents, diaeresis and Ñ/ñ
- `04_logo_tonin_chocolate.svg` — reconstructed emblem and wordmark
- `Tonin_Chocolate_Abecedario_Vectorial.pdf` — four-page presentation
- PNG previews for quick review

## Editing

SVG artwork is editable in Inkscape, Adobe Illustrator, Affinity Designer, and compatible vector editors.

## Status and limitations

This is a first-pass vector lettering system, not an installable OTF/TTF font. Review the glyph shapes and emblem against the original pencil sketches before production use. A subsequent type-design phase should normalize glyph metrics, spacing, kerning, and font tables before packaging an installable font.

## Visual direction

Rounded ornamental terminals, cocoa-brown strokes, warm ivory ground, and a restrained cacao accent. The emblem is reconstructed as four elongated ornamental elements around a central circular detail with four surrounding dots.

## Suggested next steps

1. Review and approve the overall lettering direction.
2. Refine individual glyphs against the original sketches.
3. Complete missing or inconsistent glyph details.
4. Build a font with proper metrics and kerning.
5. Test the typeface in packaging and branding applications.
